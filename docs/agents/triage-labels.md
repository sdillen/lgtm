# Triage-Labels

Die Skills kommunizieren in Begriffen von fünf kanonischen Triage-Rollen. Diese Datei bildet jene Rollen auf die tatsächlichen Label-Bezeichnungen ab, die im Issue-Tracker dieses Repos verwendet werden.

| Rolle in den Skills | Label in unserem Tracker | Bedeutung                                    |
| ------------------- | ------------------------ | -------------------------------------------- |
| `needs-triage`      | `needs-triage`           | Maintainer muss diesen Issue bewerten        |
| `needs-info`        | `needs-info`             | Wartet auf Melder für weitere Informationen  |
| `ready-for-agent`   | `ready-for-agent`        | Vollständig spezifiziert, bereit für AFK-Agent |
| `ready-for-human`   | `ready-for-human`        | Erfordert menschliche Implementierung        |
| `wontfix`           | `wontfix`                | Wird nicht umgesetzt                         |

Wenn ein Skill eine Rolle erwähnt (z. B. „das AFK-bereit-Triage-Label anwenden"), verwende die entsprechende Label-Bezeichnung aus dieser Tabelle.

Editiere die rechte Spalte, um sie an das Vokabular anzupassen, das du tatsächlich verwendest.
